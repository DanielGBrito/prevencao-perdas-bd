# Modelo de Banco de Dados - Prevenção de Perdas

Este repositório contém o modelo de banco de dados do projeto de extensão "Prevenção de Perdas no Varejo", desenvolvido na disciplina Banco de Dados e Controle de Versão (UFMS).

## 📂 Estrutura
- `modelo_banco.sql`: criação das tabelas Loja, Produto e Perda.
- Inserção de dados simulados.
- Relacionamentos via chaves estrangeiras.
